Readback agent setup

Sets up invoice-bot, a demo agent that pays from its own account through Readback. Every step that signs anything opens your wallet; read what it shows before approving. This page runs on your computer only.

1Connect your wallet

Not connected.

2Sign the mandate a message, not a transaction: free

What the agent may do. Readback refuses or holds anything else.



  
3Create the agent account one transaction, about 0.06 NEAR

    
Sign the mandate first: it tells this page which key your wallet uses.

    

    


  
4Register the agent key in intents.near no wallet needed

    
This computer uses the temporary key from step 3 to call add_public_key (1 yoctoNEAR), then deletes the temporary key from the agent account and checks it is gone.

    


  
5Fund the agent from Base

    
1Click gives you a deposit address on Base. Send USDC to it from your own Base wallet, and it arrives in the agent's balance inside intents.near. If anything fails, 1Click refunds to your address below.

    

    


  
6Check everything
